# Анти-слоп: быстрый проход по стоп-листу

Применяется ко всей статье сразу после черновика, до humanizer. Это грубый фильтр: убрать
то, что точно не несёт смысла. Тонкая работа с ритмом – в `humanizer.md`. Признак сам по
себе не доказывает, что текст написан ИИ: это повод перечитать фрагмент, а не приговор.

## Стоп-лист и замены

| Что | Примеры | Что делать |
|---|---|---|
| Пустые заходы | «в современном мире», «сегодня поговорим», «давайте разберёмся», «в этой статье мы расскажем» | начать с ответа |
| Пустые акценты | «важно отметить», «стоит отметить», «нельзя не отметить», «это и есть» | назвать факт или убрать |
| Канцелярит | «в рамках данного проекта», «было принято решение», «осуществляется мониторинг», «наблюдается тенденция» | вернуть действующее лицо и глагол |
| Рекламные штампы | «революционный», «меняет правила игры», «открывает новые горизонты», «погрузимся в мир», «путь к успеху» | заменить проверенным результатом или убрать |
| Ритуальные финалы | «в заключение», «подводя итог», «почему это важно», «что это значит на практике» | закончить выводом или действием |
| Запрещённые обещания | «24/7», «на автопилоте», «работает без тебя», гарантированные просмотры, подписчики, доход, «ИИ заменит сотрудников» | удалить; ИИ описывать через эффективность, а не пассивность |
| Постановочные контрасты | «не просто X, а Y», три лозунга подряд | сказать прямо |
| Неясный авторитет | «эксперты считают», «исследования показывают» без ссылки | дать источник или удалить |
| Выдуманное | цитаты, кейсы, опыт, отзывы, цифры | удалить или видимый плейсхолдер |
| Чатовая обёртка | «конечно, вот статья», «надеюсь, это поможет» | удалить |
| Пунктуация | «!», длинное тире «—», emoji-маркеры, жирный в каждом пункте | убрать; короткое тире «–», обычный список |
| Лишняя неуверенность | «возможно, потенциально может помочь» | одно точное утверждение; оговорку оставить, если данные правда ограничены |

## Что сохранять

- Полезные списки, таблицы и сравнения – это не слоп.
- Реальные оговорки и ограничения – даже если звучат «осторожно».
- Предметные термины – не упрощай их ради «живости».
- Фирменные обороты бренда, записанные в его тон-гайде.

## Быстрые grep-проверки

```bash
grep -nP '!(?!\[)' content/<slug>.mdx                 # восклицания вне синтаксиса картинки
grep -n '—' content/<slug>.mdx                          # длинное тире
grep -niE 'важно отметить|стоит отметить|давайте разбер|в заключение|подводя итог' content/<slug>.mdx
grep -niE '24/7|на автопилоте|гарантир|революцион' content/<slug>.mdx
```

## Самопроверка

- [ ] Первый абзац отвечает на запрос; каждый раздел добавляет факт, действие или ограничение.
- [ ] Нет фраз из стоп-листа, emoji, «!», длинного тире; кавычки «ёлочки».
- [ ] Нет выдуманных чисел, сроков, цитат, опыта и результатов.
- [ ] Смысл, оговорки и ссылки после правок на месте; изменённые факты перепроверены.
- [ ] Продукт описан только через подтверждённые возможности.
