# Графики и блоки метрик для чисел

Правило (рекомендуемый порог): если в статье от 3 сопоставимых чисел – минимум один график
или блок метрик. Числа – только из файла источников. Окно измерения, дата и оговорки –
рядом с графиком, а не где-то в тексте.

## Как это устроено в движке (принцип)

Автор пишет в статье fenced-блок `chart` или `metrics` со строгим JSON. Движок на сборке:

- превращает его в статический SVG или карточки – без JS-библиотек и запросов наружу;
- добавляет под графиком раскрывающуюся таблицу «Данные» (семантический `<table>`) и
  видимую строку источника – для доступности и для агентов;
- в `.md`-двойнике и `llms-full.txt` подставляет обычную Markdown-таблицу вместо JSON;
- падает с именем slug-а на битом JSON, неизвестном типе или разной длине рядов.

Свой движок может использовать любой формат – главное, чтобы данные оставались текстом в
HTML и Markdown, а не только картинкой.

## Какой график выбрать

| Задача | Тип |
|---|---|
| Ролик против медианы его автора | `compare` (2–3 ряда на одних подписях) или `metrics` |
| Распределение по категориям с длинными подписями | `hbar` |
| Распределение с короткими подписями | `bar` |
| До и после | `compare` с двумя рядами в одних единицах |
| Изменение во времени | `line`, подписи по порядку, 1–3 ряда |

Не смешивай разные единицы на одном графике. Не намекай на причинность, если её нет.
У `line` точки равноотстоящие – неровные интервалы оговаривай явно.

## Схема блока chart

Обязательные поля: `type`, `title`, `source` (непустой). Опционально: `unit`.

- `bar`, `hbar`: `data: [{"label": "...", "value": число}]`, 1–6 категорий (у `hbar` до 20).
- `line`, `compare`: `labels: [...]`, `series: [{"name": "...", "values": [...]}]`; длина
  каждого `values` равна длине `labels`. `line` – 1–3 ряда, `compare` – 2–3.

```chart
{"type":"compare","title":"Просмотры: ролик и обычный уровень автора","unit":"просмотры","source":"<инструмент>, <дата>; медиана по <N> последним роликам","labels":["Просмотры"],"series":[{"name":"Ролик","values":[<число>]},{"name":"Медиана автора","values":[<число>]}]}
```

## Схема блока metrics

`items`: 1–12 объектов с `label` и `value` (строки), опционально `delta` и `trend`
(`up` / `down` / `neutral`). Плюс обязательный `source`.

```metrics
{"items":[{"label":"Просмотры ролика","value":"<число>","delta":"×<k> к медиане","trend":"up"},{"label":"Медиана автора","value":"<число>"}],"source":"<инструмент>, <дата>"}
```

Стрелка тренда показывает направление, а не оценку «хорошо/плохо».

## Оговорки рядом с графиком – примеры

- «Ролик опубликован в <год>, медиана посчитана по последним роликам <период>: окна не
  совпадают, сравнение ориентировочное.»
- «Сохранения и пересылки в выборке не пришли – сравнение только по просмотрам.»
- «Свежие ролики ещё набирают просмотры.»

## Проверка

- [ ] Каждое число графика есть в файле источников.
- [ ] Источник и дата видимы под графиком.
- [ ] Оговорки про окна и пропавшие поля – рядом.
- [ ] График читается на ширине 360px в обеих темах; таблица «Данные» раскрывается.
- [ ] В `.md`-двойнике вместо JSON – таблица.
